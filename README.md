# odin-recipes-redux
## Odin Recipes: Take Two, Electric Boogaloo
This project is a basic recipe site, themed to some of my favorite fictional characters. It has an index page and links to three "recipes" which explain the key elements I associate with each character and discuss how their arcs make them who they are. 

This project is incredibly self-indulgent, and each recipe is prefaced by an introduction explaining why each character has earned a place in the Staryboy Recipe book.

Upon completion of this project, I will have demonstrated specific HTML skills. The skills demonstrated are:

- creating pages
- linking to other pages
- inserting images in pages
- creating ordered and unordered lists
